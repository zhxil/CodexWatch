# Codex Watch v1.0.0

首个 Windows 11 x64 自包含版本。

## 功能

- 精简任务栏胶囊：显示剩余额度与今日本机 Token 用量。
- 悬停摘要：自动重置时间、可用手动重置次数和各份机会的失效时间。
- 圆环额度详情，可固定为桌面悬浮面板；支持系统浅色和深色主题。
- 独立设置页面：额度预警、重置前提醒、手动重置机会到期提醒、免打扰和刷新周期。
- 当前用户开机启动快捷方式与单实例运行。
- 修复深色弹出卡片的原生白色边框。

## 使用

1. 下载 `CodexWatch-v1.0.0-win-x64.zip` 并完整解压至固定位置。
2. 先安装并登录 Codex，再双击文件夹内的 `CodexWatch.exe`。
3. 默认显示任务栏摘要；单击展开详情，图钉固定面板，齿轮打开设置。
4. 可在设置中开启开机启动。移动程序目录后，需要在新位置重新开启。
5. 如找不到 Codex，可设置环境变量 `CODEX_EXE` 为 `codex.exe` 的完整路径。

已包含 .NET 与 Windows App SDK 运行时，无需单独安装；请保留文件夹中的依赖文件。本版本为便携目录包。

额度由 Codex 服务端返回；今日 Token 统计来自本机会话记录，不代表账户整体计费额度。服务端没有提供的次数或失效信息会显示为未知。

## 验证与边界

已在当前 Windows 11 机器上验证自包含包启动、任务栏摘要、悬停不抢焦点、详情和设置交互，并通过 24 项提醒策略检查。深色实机截图见仓库 README。

任务栏嵌入目前面向主屏、水平、居中的 Windows 11 任务栏；左对齐时保留托盘入口。多屏、自动隐藏任务栏及干净虚拟机兼容性未完成完整验证。开机启动已验证快捷方式及系统识别，尚未完成真实重启登录验证。

校验下载文件可使用同页的 `SHA256SUMS.txt`。
